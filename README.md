# Spring MVC Community Project

## 프로젝트 소개
Spring MVC 기반 커뮤니티 홈페이지 프로젝트입니다.

## 개발 환경
- Java 8
- Spring Framework 4
- MyBatis
- MySQL
- JSP
- Apache Tomcat 9.0
- Eclipse IDE

## 주요 기능
- 회원가입 / 로그인
- 게시판 CRUD
- 댓글 기능
- 파일 업로드
- Spring Security 로그인 인증
- WebSocket 채팅

## 담당 역할
개인 프로젝트 100%

## 실행 방법
1. MySQL DB 생성
2. SQL import
3. Tomcat 연결
4. Maven install
5. Run on Server
